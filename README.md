# CS 421 Type Inferencer Practice

Practice page for the PicoML `gather_exp_ty_substitution` cases (Var, MonOp, BinOp, If, Fun, App, Let, LetRec, Raise, TryWith).
Write a case in the editor, click **Save & Grade**, and it runs test cases against a real OCaml 4.14 toplevel (js_of_ocaml) in your browser.

Live: https://hindra2.github.io/cs421-type-inferencer-practice/
